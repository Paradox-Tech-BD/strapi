03 / Computation

Currency is part of the tax context.

Phase 2 configuration
baseCurrency: 'USD'
supported: ['USD', 'BDT']
exchangeRates: { USD: 1,
  BDT: 120 }
The configured exchange rate establishes the contract: 1 USD converts to 120 BDT before tax and totals are calculated.
Checkout calculation path

Normalize once, calculate once, persist an auditable result.

Preview and create both resolve the same currency, promotion, tax-rule, and exemption context so storefront estimates do not drift from the stored order.

01

Normalize

Resolve region and requested checkout currency.

02

Validate

Reject currencies outside the configured supported set.

03

Convert

Convert product or cart price snapshots into the checkout currency.

04

Select

Choose active rules for the requested region and currency.

05

Exempt

Match customer, tag, domain, code, subtotal, and time window.

06

Persist

Store calculated tax context under order metadata for audit.

CompatibilityCalls without currency context keep the legacy result shape: { taxAmount, effectiveRate, rules }. Context-aware calls add gross tax, exemption information, net tax, and currency.
